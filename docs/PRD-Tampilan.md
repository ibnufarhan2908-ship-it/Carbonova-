# PRD Tampilan - Carbonova

## 1. Tujuan
Dokumen ini menjelaskan tampilan / UI dari website Carbonova.
Fokusnya hanya pada desain, layout, dan halaman, bukan fitur keseluruhan.

## 2. Daftar Halaman
1.  Halaman Login
2.  Halaman Petunjuk
3.  Halaman Home / Molekul 3D
4.  Halaman Our Team

## 3. Halaman Login
- Input: Email / Username dan Password
- Tombol: Login
- Setelah login, user diarahkan ke Halaman Petunjuk

## 4. Halaman Petunjuk
- Menampilkan cara penggunaan website
- Isi petunjuk:
    1. Pilih molekul (Metana, Etana, dll)
    2. Geser untuk memutar molekul 3D
    3. Scroll untuk zoom in / out
    4. Klik info untuk melihat keterangan
- Tombol: "Saya Mengerti, Lanjut ke Web" -> ke Halaman Home

## 5. Halaman Home / Molekul 3D
- Menampilkan molekul 3D (Metana, Etana, dll)
- User bisa memutar, zoom, dan memilih molekul lain
- Tampilan utama website

## 6. Halaman Our Team
- Menampilkan anggota kelompok Carbonova
- Isi: Nama, NIM / Kelas, Tugas masing-masing
- Foto anggota (jika ada)

## 7. Warna & Font
- Warna Utama: Hijau (sesuai tema Carbonova)
- Warna Background: Putih / Abu-abu muda
- Font: Sesuai yang dipakai di proyek (misal: Inter / Poppins)

## 8. Komponen yang Dipakai
- Navbar / Header
- Tombol (Button)
- Card Molekul
- Modal / Pop-up (jika ada)
